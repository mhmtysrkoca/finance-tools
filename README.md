# Bileşik Getiri Hesaplayıcı
Tek dosyalık (HTML/JS) bileşik getiri aracı. Anapara, düzenli katkı, faiz ve vade girerek yıllık tablo, grafik ve CSV çıktısı üretir.
- Dosya: `index.html` (veya `compound-interest-calculator.html`)
- Özellikler: Aylık/3 aylık/yıllık/günlük bileşik, toplam katkı ve kazanç özeti, CSV indir.
